# Third-party assets

## Project Zomboid skill icons

The 35 `TGSRR_Skill_*` Tracker icons are Project Zomboid artwork extracted from
the game files and distributed in 32 x 32 form with **OSRS XP Drops
Retextured**. The artwork belongs to Project Zomboid and The Indie Stone. The
Workshop mod is recorded here as the immediate extraction/distribution source,
not as the artwork owner.

- Artwork: Project Zomboid, The Indie Stone
- Distribution source: OSRS XP Drops Retextured
- Distribution mod author: FishLord
- Distribution Workshop item: `3413529369`
- Distribution mod ID: `RUNE-EXP-RETEXTURED`
- Source filenames: `RUNE-EXP_icon_<skill>.png`

TGSRR retains its own filenames so the Tracker remains independent of the
source mod at runtime.
