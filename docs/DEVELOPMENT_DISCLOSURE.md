# Development Disclosure

## Approved statement

> Codex, a development agent powered by LLMs, has been and continues to be used
> to assist with code analysis, implementation, debugging, and documentation.
>
> Any code produced with its assistance is reviewed, quality-assured, and tested
> by people.
>
> All participant and competition data is submitted, reviewed, and approved by
> people.

## Public placement

- Place the complete statement on the Steam Workshop page beneath a
  `Development disclosure` heading. The Workshop page is the primary disclosure
  point because players see it before subscribing to the mod.
- Publish the same complete statement in a website modal opened by a
  `Development` footer link. Its direct `/development/` page provides a durable
  fallback and shareable address. The existing footer affiliation disclaimer
  remains separate.
- The in-game `mod.info` description does not need to carry the complete
  statement. It is space-constrained and is not the normal subscription decision
  point. If an in-game disclosure is later desired, use a short pointer to the
  Workshop page or website statement.

## Wording boundary

Keep the public statement identical in both primary locations. Do not broaden it
into claims that no project information was processed by Codex. The disclosure
distinguishes development assistance from the participant and competition data
that remains under human submission, review, and approval.
