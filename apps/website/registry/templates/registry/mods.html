Challenge rules

Which mods can be used?

A mod must be listed as Allowed or Required in the catalogue before it can be used in a Rat Race run. These rules guide the team's decisions and help keep the competition fair.

Rule 1: The mod is purely cosmetic

  • ✅Allowed: Changing a vehicle's texture.
  • ❌Not allowed: Adding new vehicles.
  • ✅Allowed: Adding superficial clothing items.
  • ❌Not allowed: Adding clothing with improved protection or insulation statistics.

Rule 2: The mod provides no information unavailable in the unmodded game

  • ✅Allowed: Resizing the user interface.
  • ✅Allowed: Changing the appearance of moodles.
  • ❌Not allowed: Displaying character statistic bars.
  • ❌Not allowed: Displaying zombies on the minimap.

Previous ruling examples

Generally allowed

  • Displaying experience earned by an action
  • Restyling progress bars
  • Showing which watches have alarms set
  • Resizing or restyling map symbols and text
  • Adding vehicle door animations
  • Clarifying existing moodle, trait, or occupation information
  • Minor world retextures

Generally disallowed

  • Displaying item condition outside the inventory
  • Automating skill levelling or gameplay
  • Adding player models with abilities or statistics
  • Adding or changing traits and occupations
  • Changing game mechanics, including perceived bug fixes

We want participants to enjoy their preferred mods without overcomplicating setup or creating an uneven competition. If you are unsure, ask publicly in the Discord discussions area so the answer is available to everyone, or use Submit for review on this page. Please do not request rulings by direct message.
