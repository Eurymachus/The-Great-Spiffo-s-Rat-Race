# The Great Spiffo's Rat Race

This repository contains both the Project Zomboid Workshop mod and the wider Rat
Race challenge platform.

- `Contents/` is the content published to Steam Workshop.
- `apps/website/` is the participant and administration website.
- `docs/WEBSITE_NOW.md` records the current website focus.
- `docs/MOD_NOW.md` records the current mod focus when present on the branch.
- `docs/DECISIONS.md` records settled decisions.
- `docs/IDEAS.md` parks possible future work.

For website work, start with `docs/WEBSITE_NOW.md`. Website setup instructions live in
`apps/website/README.md`.
